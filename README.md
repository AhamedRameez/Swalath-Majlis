# Swalath Majlis

Islamic reference app with **773+ installers** and **4.9⭐ rating** on Google Play Store.

## About the App

Swalath Majlis is a comprehensive Islamic reference app offering:
- 📖 Quran access with offline caching
- 🕌 Prayer times and Hijri calendar
- 📿 Interactive Tasbih counter with history
- 📚 500+ duas library
- 🔴 Live weekly streaming (every Thursday)
- 📢 Real-time announcements
- 🎨 Dual themes

## Tech Stack

| Component | Technology |
|-----------|------------|
| Frontend | Flutter & Dart |
| Backend | Firebase Firestore |
| Authentication | Firebase Auth |
| Push Notifications | Firebase Cloud Messaging (FCM) |
| Local Storage | Hive |
| State Management | GetX |
| Video Streaming | YouTube Player |

## Key Features

- **Offline-First**: Quran text and duas cached locally using Hive
- **Live Streaming**: Weekly Thursday sessions
- **Push Notifications**: FCM for announcements
- **Admin Panel**: 15+ screens for content management
- **Multi-language Support**
